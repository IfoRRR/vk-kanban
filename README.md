# Канбан

Доски, колонки и карточки для командной работы. У доски есть владелец и участники. Карточку можно перенести, поменять порядок, назначить исполнителя, поставить срок и оставить комментарий.

Стек: Go, WebSocket, Vue.

## Запуск

```bash
go run ./cmd/cases
```

Страница доски: http://127.0.0.1:8094/board/

Данные пишутся в `data/board.json`. Схема таблиц: `internal/cases/board.sql`.

Живой экземпляр: http://132.243.194.181:8081/board/

На общей доске можно смотреть без регистрации. Свои доски, участники и переименование открываются после входа. Кнопки «Демо владельца» и «Демо участника» заходят без почты.

## Что есть

- регистрация и вход
- создание, переименование и удаление своей доски
- колонки: создание и переименование
- карточка: название, описание, исполнитель, срок, перенос между колонками, порядок
- комментарии
- метки и поиск, чек-лист, ссылка-вложение, история изменений
- перетаскивание и обновление по WebSocket
